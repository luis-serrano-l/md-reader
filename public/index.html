md-reader

Add notes to read

md-reader opens only the Markdown (.md) files of what you add here.

Add from GitHub

Paste the address of a repository; owner/repository is enough. You then choose which of its folders to add. The address of one folder or one .md file adds just that. md-reader only reads the repository and never changes it.
